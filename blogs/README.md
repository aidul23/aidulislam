# Blog Markdown Guide

Place blog posts in this folder as `*.md` files.

## Required metadata block

```md
---
title: "Post title"
date: "2026-02-10"
summary: "Short summary for listing pages"
tags: ["Agentic AI", "RAG"]
cover: "blogs/assets/post-slug/cover.jpg"
slug: "post-slug"
---
```

## Content

After metadata, write normal markdown (headings, tables, images, code).

Image example:

```md
![Caption](blogs/assets/post-slug/figure1.png)
```
